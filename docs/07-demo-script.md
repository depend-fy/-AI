# 智鉴 AI · 演示脚本（可重复运行，含断网兜底）

> 目标：6–8 分钟内让评委看懂三件事——
> ① 它真的去查了外部证据；② 它**拒绝**在没有证据时下结论；③ 它连自己的修正都会否决。
> 全部输出都是**真实运行结果**，可以用下面任一方式原样复现。

## 一、演示前 5 分钟准备

```powershell
cd <你的项目目录>\verimind-ai

# 1) 环境与密钥自检（应看到：主模型可用 + 独立复核员可用 → 多模型协同）
.\.venv\Scripts\python.exe scripts\check_llm.py

# 2) 预跑一遍，把结果写进缓存（现场断网也能复现同样的报告）
.\.venv\Scripts\python.exe scripts\run_demo.py --id real_doi_wrong_claim
.\.venv\Scripts\python.exe scripts\run_demo.py --id fake_doi
.\.venv\Scripts\python.exe scripts\run_demo.py --id internal_conflict

# 3) 启动界面
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

**断网兜底**：模型与检索结果都命中本地缓存，第二次运行同一文本**0 次计费调用、约 0.25 秒**；
报告里会写明「本次有 N 次模型调用命中了本地缓存」。若现场完全断网且缓存为空，
把 `.env` 的 `VERIMIND_LLM_PROVIDER=mock` 改成离线规则引擎模式——功能降级但流程仍然完整，
报告中会**如实标注**「离线模拟」。

## 二、四幕脚本

### 第 1 幕（约 1.5 分钟）：虚构 DOI —— "它凭什么说这条引用不存在？"

- **操作**：工作台 → 载入示例「虚构文献 + 数值夸大」→ 开始检测
- **输入**：`据一项发表于 2023 年的研究（DOI: 10.xxxx/verimind.2023.001）显示，该团队提出的新方法可将图像分类准确率提高 40%……`
- **真实结果**：
  - DOI 前缀不合规 → 命中规则 `N5`（疑似引用不存在，严重度中）；**检索 0 次**，并说明"格式不合规的 DOI 无法提交给注册机构"
  - `提高 40%` 无任何出处 → 命中 `N2`（缺少必要证据）
  - 因果类结论 → 命中 `N3`（逻辑推断过度）
  - 所有结论状态都是**「证据不足」**而不是「存在矛盾」
- **话术**："注意它没有说'这是错的'——它说的是'这条引用在格式上就不合规，而且我们还没查过它'。
  在一个还没有证据的阶段就下结论，是这类系统最常见的失败方式。"

### 第 2 幕（约 2.5 分钟）：真实 DOI + 年份写错 —— 核心演示

- **操作**：载入示例「真实 DOI + 可疑年份与结论」→ 开始检测 → 打开报告页
- **输入**：`《自然》杂志在 2008 年发表的一项研究（DOI: 10.1038/nature12373）证实，钙钛矿太阳能电池的转换效率可以轻松突破 50%。`
- **真实结果**（来自真实 Crossref / OpenAlex / DeepSeek / agnes）：
  - **年份类主张 → 「存在矛盾 / 时间信息错误」（严重度高）**：Crossref 与 OpenAlex **都**记录该文献发表于 **2013 年**
  - **DOI 类主张 → 「已核实」**，并明确写着"这只证明文献存在，不代表其内容支持原文的任何结论"
  - **内容类主张 → `N6`「证据不足（缺少必要证据）」**：查到了论文，但拿不到摘要，**拒绝**判断它是否支持 50% 这个说法
- **话术**："这是整个系统的核心：『文献是真的』和『文献真的这么说』是**两个问题**。
  它核了前者，对后者明确说'我不知道'——而不是因为查到论文就默认它支持原文。"

### 第 3 幕（约 1.5 分钟）：修正与独立复核 —— "连它自己的修改都会被否决"

- **操作**：同一份报告 → 向下滚动到「修正建议与独立复核」
- **真实结果**：
  - 修正员提出 `2008 年 → 2013 年`，引用 Crossref + OpenAlex 两条证据；**三项确定性检查全部通过**
  - **独立复核员（agnes-3.0-flash，与修正员不是同一个模型）否决了这条修改**，理由是：
    *"该 DOI 的真实标题是纳米尺度测温，与原文声称的钙钛矿太阳能电池主题不符；
    只改年份等于默认了这个错误的文献对应关系"*
  - 最终：该修正**不被采用**，报告列出两个真正未解决的问题
- **话术**："如果它只是把 2008 改成 2013，这条引用看起来就'对'了——但错的文献对应关系被合法化了。
  复核员拦住的是一个**看起来正确、实际上更危险**的修改。这就是我们坚持'复核不通过就不改'的原因。"

### 第 4 幕（约 1.5 分钟）：评测页 —— "不隐瞒失败"

- **操作**：切到「评测」页 → 选择 `B2 证据增强（本项目完整流程）` → 用 `--ids` 那 6 条或直接看已有结果
- **真实结果**：
  - B0（直接问模型，全量 100 条）：精确率 61.4% / 召回率 68.6% / **误报率 44.9%** / 证据可追溯率 0%
    —— 它只在"文内自相矛盾"上判有问题（来源冲突 3/3 全对），
    而年份错误、虚构文献这 9 条**全部漏检**（不检索就无从核验）
  - B2（完整流程，20 条全跑）：精确率 90.9% / 召回率 100% / F1 95.2%、**误报率 10%（1 条）**、
    六状态一致率 85%、证据可追溯率 75%、修正成功率 80%、剩余错误率 20%、**新增错误率 0%**；
    **3 条失败案例全部公开**（G02 误报 / G05 状态不精确 / G11 漏判）
  - 页面显著标注：**样本量极小**、**主要指标是 AI 起草的标注**、**同源偏差风险**、
    **B0（原模型自检）未实现**
- **话术**："我们最看重的指标不是精确率，是**误报率**。
  一个总是说'这可能有问题'的系统在评测里会很漂亮，但没人敢用。
  另外，这一页自己写了三条对我不利的局限——包括标注是 AI 起草的。我们宁可把这些放在台面上。"

## 五、一句话总结（可反复使用的收尾）

> **「我们不做一个更会说话的模型，我们做一条能被人追问的流水线：
