## 一、项目说明

### 1.1 一句话定位

**面向科研文本的事实核验 Agent**：对论文、综述与研究报告中的事实性主张逐条核验，
输出可追溯的证据、可解释的判定与可复核的修正建议。

### 1.2 解决的问题（真实问题）

科研写作中引用与结论不匹配、DOI 不存在、年份与数值错误是高频且代价高昂的问题。
以一篇含 100 条事实性主张的综述为例，逐条核对文献是否存在、年份期刊是否一致、
文献内容是否支持该表述，人工需要数小时至数日，且难以保证一致性。

大模型可以辅助，但**不能作为判断依据**：本项目的实测数据显示，直接把文本交给模型判断，
误报率高达 **44.9%**——接近一半的正确内容会被判成有问题，且每条结论都无法追问（证据可追溯率为 0%）。

### 1.3 方法（与赛题五环节的对应）

| 环节 | 实现 |
| --- | --- |
| **任务规划** | 拆分事实主张 → 判定主张类型 → 决定检索策略（DOI 精确查询 / 书目检索 / 预印本检索 / 明确不检索并说明原因） |
| **工具调用** | 真实调用 Crossref、OpenAlex、arXiv 三个公开学术数据源；带限速、结果缓存与原始响应留档 |
| **执行反馈** | 11 步流水线实时回传阶段进度；每一步输入输出均为结构化数据 |
| **结果验证** | 双层验证：确定性规则表裁决（6 种状态 / 8 类问题 / 严重度）＋ 跨厂商独立复核（三项确定性检查 + 两项语义检查） |
| **异常处理** | 区分「服务端明确 404」与「网络失败」；模型调用失败降级为规则引擎并如实声明；检索失败标注「暂无法核验」；命中缓存标注数据来源 |

### 1.4 核心设计原则

1. **模型不作为结论来源**：大模型只产出结构化判断；状态与问题类型由可解释的规则表裁决。
2. **判断分层**：区分「文献是否存在」「书目信息是否一致」「内容结论是否被支持」，
   仅元数据级证据**不得**用于内容层面判断（由数据契约强制）。
3. **无证据不判错**：「证据不足」「暂无法核验」为一等公民状态。
4. **修正必须过独立复核**：改事实须有证据；复核未通过（甚至未完成）一律不写入正文。
5. **不给假精度**：不输出未经校准的概率化评分。

## 三、运行与验证证据

### 3.1 核心对比实验（100 条标注测试集）

| 指标 | B0 直接问模型 | **B1 本项目方法** |
| --- | --- | --- |
| 精确率 | 61.4% | **97.6%** |
| 召回率 | 68.6% | **78.4%** |
| F1 | 64.8% | **87.0%** |
| 误报率 | **44.9%** | **2.0%** |
| 六状态完全一致率 | 51.0% | **79.0%** |
| 证据可追溯率 | **0.0%**（定义上为 0） | **69.0%** |
| 修正成功率 | 0.0% | **79.3%** |
| 新增错误率 | 0.0% | **0.0%** |

**结论**：B0 与 B1 使用同一模型，差异只来自方法。直接询问模型的误报率是 44.9%（把正确内容判成有问题），且结论无法追问；本项目把误报率压到 2.0%，同时让 69.0% 的结论可点开证据。

### 3.2 测试集构成（100 条，7 类）

| 类别 | 条数 | 真值来源 |
| --- | --- | --- |
| 正确事实 | 15 | Crossref 实测（19 个真实 DOI，记录实际年份与标题） |
| 明确错误事实 | 15 | 同上（年份写错，注册记录可证伪） |
| 虚构文献 | 14 | Crossref 实测返回 404（7 个）+ 格式不合规（4 个） |
| 真实文献但错误引用 | 14 | 文献真实但所述内容与主题不符 |
| 证据不足 | 14 | 构造用例（中文自由文本、无可检索标识） |
| 来源冲突 | 14 | 文内自相矛盾（同一 DOI 两个年份 / 同一指标两个数值） |
| 修正质量 | 14 | 期望修正结果可判定 |

标注状态：**100/100 经人工确认**（其中 20 条为书面逐条勾选，80 条为使用者口头确认）。
