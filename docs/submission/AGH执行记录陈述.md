## 五、复现方式

### 5.1 只读调用链（免审批，可即时复现）

```powershell
# 我方 CLI 安装位置由调用方环境决定
$node = "<node 可执行文件>"
$cli  = "<agnes-harness>\packages\cli\dist\local\agnes.mjs"

$prompt = "请只读取文件（不要执行命令、不要修改文件）。依次阅读 README.md、" +
          "evaluations/b0-direct-100.json、evaluations/b1-agent-100.json，" +
          "用表格报告 B0 与 B1 在精确率、召回率、F1、误报率、证据可追溯率上的数值。"

& $node $cli -p $prompt --profile local-dev --cwd "<项目目录>" --mode text
```

执行过程中，终端将实时打印 `- tool read · ok · Nms`，即 §二 所列调用链。

### 5.2 命令类执行（需调用方授权一次）

**方式 A：我方 Web 工作台（记录最完整）**

1. 打开我方工作台 `http://127.0.0.1:4180`
2. 新建会话，工作目录选择项目根目录
3. 提交如下任务：

   > 请在当前目录依次执行以下两条命令并原样报告结果：
   > （1）`.\.venv\Scripts\python.exe -m pytest -q`
   > （2）`.\.venv\Scripts\python.exe scripts\run_demo.py --id real_doi_wrong_claim`
   > 汇报每条命令的退出状态，以及输出中的关键数字（测试通过数、主张条数、状态分布、
   > 检索与模型调用次数）。不要修改任何文件。

4. 审批卡片出现时，核对命令后选择允许（一次性或本会话）
5. 于会话轨迹页留存记录截图（含工具调用序列、耗时与审批卡片）

**方式 B：命令行等待审批**

```powershell

```

`--park` 使该次调用**等待审批**；在 Web 工作台确认后继续执行。
