## 一、外部学术数据接口（本作品的核心工具调用）

三个数据源均为**公开、免密钥**的学术元数据接口，本作品通过 HTTPS 直接调用：

| 接口 | 来源 | 用途 | 说明 |
|---|---|---|---|
| Crossref REST API | https://api.crossref.org | 按 DOI 精确核验文献是否存在、实际发表年份与标题 | 注册机构官方接口；请求头带联络邮箱以进入"礼貌池" |
| OpenAlex API | https://api.openalex.org | 书目检索与二次交叉验证（同一 DOI 的独立来源） | 开放学术图谱；摘要以倒排索引形式提供，由本项目代码重建 |
| arXiv API | https://export.arxiv.org/api | 预印本检索（无 DOI 的论文） | Atom Feed 格式 |

**使用方式**：仅做**只读查询**，不下载全文、不批量抓取；每个来源设有最小请求间隔（默认 1 秒）、
失败重试与本地缓存（默认 24 小时）。

## 二、大模型服务

| 服务 | 来源 | 用途 | 说明 |
|---|---|---|---|
| DeepSeek 开放平台 | https://api.deepseek.com | 主模型 `deepseek-chat`：主张拆分、事实审查、修正建议 | 按调用计费，使用队伍自有密钥 |
| Agnes | https://agnes-ai.cn | 独立复核模型 `agnes-3.0-flash`：复核修正建议 | 按调用计费 |

**为什么用两个厂商的模型**：本作品要求"改的人"与"检查改得对不对的人"不是同一个模型；
跨厂商可以降低同源偏差。界面与报告会如实标注当前运行模式（多模型协同 / 单模型多角色模拟 / 离线模拟）。

> **模型调用范围说明**：除上述两个模型外，本作品**未接入**任何其他厂商模型。
> 若赛事对可用模型有额外限定，请以赛事规定为准——本清单仅如实说明技术实现现状。

## 四、数据

| 数据 | 来源 | 说明 |
|---|---|---|
| 标注测试集（100 条） | **本队自建** | 覆盖 7 类用例；凡涉及文献的真值均经 Crossref **实测**锚定 |
| DOI 真值 | Crossref 实测 | 26 个候选 DOI：19 个确认存在（记录实际年份与标题）、7 个确认返回 404 |
