## 一、AGH 作用

| 项目              | 内容                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------- |
| **AGH 是什么**     | Agnes Harness，智能体的运行与执行底座，为 Agent 提供持续运行、工具编排与执行记录能力                                         |
| **本作品如何使用**     | 本作品在 AGH 底座环境中开发与运行；AGH 负责智能体的运行与调度，本项目负责科研文本核验的领域能力                                         |
| **AGH 承担的具体职责** | ① 提供智能体运行环境与执行调度；② 统一接入并管理模型账号（DeepSeek 与 Agnes），密钥存于 AGH 安全设置，代码中不保存长期密钥；③ 记录执行过程，供复核与答辩时回看 |
| **本项目承担的具体职责**  | 主张拆分、外部文献检索、可解释规则裁决、修正建议生成、独立复核；六态判定与八类问题归因；证据链与规则编号的可追溯输出                                   |
| **执行闭环**        | 任务规划 → 工具调用 → 执行反馈 → 结果验证 → 异常处理（详见《作品说明与技术方案》技术方案章节）                                        |

## 二、Agnes 模型信息

| 项目              | 内容                                                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **模型名称 / 版本标识** | **agnes-3.0-flash**（Agnes 3.0 Flash）                                                                                      |
| **接入方式**        | 经 AGH 统一接入；服务端点 `https://api.agnes-ai.cn/v1`（OpenAI 兼容协议）                                                                 |
| **参与环节**        | **独立复核**——对修正建议逐项复核，共 5 项检查：<br />① 修正内容是否有证据支持<br />② 证据与修正后表述是否匹配<br />③ 是否引入新的事实错误<br />④ 原始问题是否已解决<br />⑤ 是否出现新的无依据结论 |
| **为什么放在这一环**    | 本作品要求"改的人"与"检查改得对不对的人"不能是同一个模型。Agnes 作为**另一家厂商**的模型承担复核，可降低同源偏差（self-preference bias）                                     |
| **复核结果如何被使用**   | 复核未通过或未完成的修正**一律不写入正文**；复核结论（含未通过与理由）原文展示在报告中                                                                             |
| **上下文窗口**       | 200,000 tokens（AGH 账号配置）                                                                                                  |
| **备注**          | 本项目**未接入**除 DeepSeek 与 Agnes 之外的其他厂商模型                                                                                    |
