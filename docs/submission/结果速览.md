## 一句话结论

**直接把文本交给模型判断，44.9% 的正确内容会被判成有问题，且每条结论都无法追问；
本方法把误报率压到 2.0%，并让 69.0% 的结论可以点开证据。**

## 技术要点（与赛题五环节对应）

| 环节 | 实现 |
|---|---|
| **AGH 运行底座** | 本作品在 AGH（Agnes Harness）底座环境中开发与运行；模型服务由 AGH 统一接入（DeepSeek 默认 + Agnes 独立复核），密钥由 AGH 管理 |
| **任务规划** | 拆分事实主张 → 判定主张类型 → 决定检索策略（DOI 精确查询 / 书目检索 / 预印本检索 / 明确不检索并说明原因） |
| **工具调用** | 真实调用 Crossref、OpenAlex、arXiv；带限速、结果缓存与**原始响应留档** |
| **执行反馈** | 11 步流水线实时回传阶段进度；每步输入输出均为结构化数据 |
| **结果验证** | 双层验证：确定性规则表裁决（6 状态 / 8 类问题 / 严重度）+ 跨厂商独立复核（3 项确定性检查 + 2 项语义检查） |
| **异常处理** | 区分「服务端明确 404」与「网络失败」；模型失败降级为规则引擎并**如实声明**；检索失败标注「暂无法核验」；缓存来源标注 |

## 诚实边界（主动公开）

- **21 条失败案例全部公开**（含误报、漏判、状态不精确），不做筛选；
- 直接问模型的对照（B0）**误报率 44.9%**，这个数字我们照实写；
- 开发中真实修复的缺陷：一处让修正成功率虚高的指标 Bug、一处把正确修正误判为"编造"的 DOI 正则 Bug；
- 标注集为自建（100 条），其中 80 条为使用者口头确认，**未计算标注一致性（kappa）**；
- 只读到摘要，不通读全文；中文文献与非学术事实无法核验。
