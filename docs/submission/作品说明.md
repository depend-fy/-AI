> 队伍「旭日伴粽同行小队」｜ 编号 U071 ｜ 本科生组 ｜ 队长 宗佳雨 ｜ 成员 郑子旭

## 项目一句话

AI 生成或辅助撰写的科研文本里，最危险的错误不是明显胡说，而是**看起来很像真的**：DOI 不存在、
年份与注册记录不符、文献真实但没说过那句话。智鉴 AI 是一个面向科研文本的**事实核验 Agent**：
对文本中的事实性主张逐条核验，输出**可追溯的证据、可解释的判定与可复核的修正建议**——
且**不把模型判断当作结论**。

## 核心结果

同一批 100 条人工确认的标注用例、**同一个模型**，唯一差别是有没有外部证据与规则裁决：

| 指标 | B0 直接问模型 | **B1 本项目方法** |
|---|---|---|
| 精确率 | 61.4% | **97.6%** |
| 召回率 | 68.6% | **78.4%** |
| F1 | 64.8% | **87.0%** |
| **误报率** | **44.9%** | **2.0%** |
| 证据可追溯率 | **0%** | **69.0%** |
| 修正成功率 | 0% | **79.3%** |

**直接问模型时，44.9% 的正确内容会被判成有问题，且每条结论都无法追问。**

## 复现命令

```powershell

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env      # 填入模型 API Key

# 2) 全量测试（离线、零成本）
.\.venv\Scripts\python.exe -m pytest -q                    # 245 passed

# 3) 单条文本完整报告
.\.venv\Scripts\python.exe scripts\run_demo.py --id real_doi_wrong_claim

# 4) 三份评测存档（b1 与 rules 可用缓存复跑）
.\.venv\Scripts\python.exe scripts\run_evaluation.py --baseline b0 --all
.\.venv\Scripts\python.exe scripts\run_evaluation.py --baseline b1 --all

# 5) 界面
powershell -ExecutionPolicy Bypass -File .\run.ps1
```
