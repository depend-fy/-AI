## 附：三个硬缺口的具体建议

### 1. 在线体验链接（#8）

| 方案                        | 成本    | 说明                                 |
| ------------------------- | ----- | ---------------------------------- |
| Hugging Face Spaces       | 免费    | 支持 Streamlit；把仓库接上去即可，公开链接免登录      |
| Streamlit Community Cloud | 免费    | 直接指向 GitHub 仓库；需在 Secrets 里填模型密钥   |
| 临时内网穿透                    | 免费但短时 | 仅适合录制视频时用，**不适合作为评审期链接**（评审期须长期有效） |

> ⚠️ 部署时**不要把密钥写进代码**；用平台的 Secrets 功能。  
> 另建议：部署版默认走**离线模拟或缓存**，避免评委点击时产生费用。

### 2. 视频链接（#12）

- 平台不限；**不要设密码**，或把密码一并提交
- 评审期间链接必须有效 → 优先选不会过期的平台（B 站 / YouTube），网盘链接容易失效
- 建议在视频简介里写明：队伍名、编号、时长、章节时间点

### 3. 公开内容（#19，要求最容易被忽略）

- 需要「平台 + 有效链接 + 截图 + 发布日期」四要素齐全
- 建议内容：项目介绍 + 一张界面截图 + 一句话结论（直接问模型误报率 44.9% vs 本方法 2.0%）
- 发布即可，**不需流量**；注意留存**带日期的截图**（网页截图或平台后台截图）
